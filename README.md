# COA Sales Delegate Live Tracking

**Odoo Module** | Versions: 17.0, 18.0, 19.0 | License: OPL-1

## Description
Live GPS location tracking and interactive OpenStreetMap dashboard for field sales delegates.

## Author
**Community of accountants (COA-Egypt)**
- Website: https://www.coa-egy.com
- Support: info@coa-egy.com

## Installation
1. Download and place in your Odoo addons directory
2. Update the apps list
3. Install `coa_delegate_tracking`
