Frequently Asked Questions

Do field sales representatives need to install a special mobile app?

No. The system utilizes modern HTML5 Geolocation supported by all mobile web browsers (Safari on iOS, Chrome on Android). Delegates simply open Odoo in their browser.

How accurate is the GPS coordinate tracking?

The browser utilizes the device's hardware GPS and cell-tower triangulation, typically delivering accuracy within 5 to 15 meters outdoors.

Can supervisors see historical customer visits and routes?

Yes. Every location update and customer check-in is logged with a timestamp, allowing supervisors to review historical visit logs and travel routes per delegate.
